# Баннеры для Луны

Бот сам подхватит файлы из этой папки. Имя файла = экран. Формат: `png` (лучше), `jpg` или `webp`.

Пока файла нет, уходит только текст — бот уже живой.

## Техника

- Размер: **1280×720** (16:9). Можно 1280×640.
- Эмодзи — герой кадра, крупно, по центру или чуть правее.
- Текста на картинке почти нет: Telegram давит jpeg, мелкие буквы умрут.
- Поля: 80px со всех сторон, низ чуть спокойнее — на него ляжет подпись.
- Без обводки «сторис», без градиентной радуги, без 3D-шариков.
- Один и тот же свет и зерно на всех десяти кадрах, как одна плёнка.

## Палитра

| роль | hex | куда |
| --- | --- | --- |
| молоко | `#F4EBE3` | фон welcome, home, calendar, settings |
| пыльная роза | `#C45C6A` | красные дни, тёплые акценты |
| голубая пудра | `#7BA3C9` | голубые дни |
| чернила | `#2B2422` | если всё же будет слово |
| персик | `#E7C1B0` | секс, советы |
| пепел | `#B9A79A` | задержка, настройки |

Фон не чисто-белый и не кислотно-розовый. Бумага, пыль, чуть теплого света.

## Что нарисовать

Клади файлы сюда: `cycle-bot/assets/banners/<имя>.png`

| файл | смайлик | фон | настроение |
| --- | --- | --- | --- |
| `welcome.png` | 🌙 | молоко | первый экран. Луна тонкая, не детская. Можно крошечную точку-звезду. |
| `home.png` | 🌸 | молоко | «сегодня». Один цветок, не букет. |
| `calendar.png` | 📅 | молоко | пустой лист/календарь, без цифр-каши. |
| `period.png` | 🔴 | пыльная роза, приглушить | красные дни. Круг, не капля крови и не прокладка. |
| `fertile.png` | 💙 | голубая пудра | голубые дни. Сердце или капля, спокойно, не «любовный клипарт». |
| `sex.png` | 💋 | персик | близость. След помады или губы, без тел и без шуток. |
| `delay.png` | ⏳ | пепел | задержка. Песочные часы, пауза, тишина. |
| `tips.png` | 💌 | персик / молоко | советы. Конверт или записка, не учебник. |
| `partner.png` | 💕 | молоко с тёплым краем | партнёр. Два знака, не семейная открытка. |
| `settings.png` | ✨ | пепел-молоко | настройки. Тихий блеск, не шестерёнка из Windows 95. |

## Как держать стиль

1. Все смайлики **Apple / iOS**, один набор. Не мешай Twitter, Samsung и 3D.
2. Смайлик занимает примерно **40–50% высоты** кадра.
3. Лёгкая тень под ним, как у предмета на столе, не неон.
4. Если хочется слово на баннере — только одно, строчными: `луна`, `красные`, `голубые`. Шрифт: что-то вроде *Ivy Mode*, *Playfair*, *Manrope*. Не Comic Sans, не Impact.
5. `period` и `fertile` должны быть парой: один тёплый, один холодный, одинаковая композиция.
6. `sex` не делай краснее `period`, иначе экраны слипнутся. Персик / пыльная губа, не алый.
