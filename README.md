# луна

Тихий Telegram-бот календаря цикла.

Красные дни ставишь ты. Голубые считаются сами (овуляция ≈ длина цикла − 14, окно — 5 дней до неё и день после). Можно отметить близость, задержку и человека, которому это видно.

Это не врач и не контрацепция.

## Что умеет

- карта сегодняшнего дня и фазы
- календарь месяца: красные `°`, голубые `*`
- старт кровотечения → пересчёт голубых
- секс (с защитой / без / молча), партнёру — только если откроешь
- задержка, когда прогноз уже прошёл
- советы по фазе
- одноразовая ссылка для партнёра
- утренние тихие напоминания в 9:00

## Запуск

Нужен **Python 3.11** (на 3.14 пакеты Telegram пока капризные).

1. Напиши [@BotFather](https://t.me/BotFather): `/newbot`, имя **луна**, юзернейм какой получится.
2. Команды боту:

```
start - открыть луну
menu - сегодняшний цикл
help - как это работает
```

3. В этой папке:

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

4. В `.env` вставь токен и юзернейм без `@` — без юзернейма ссылка партнёру будет вида `/start p_код`.
5. `python run.py`

Баннеры: см. `assets/banners/README.md`. Положи png с теми именами — подписи сами сядут на картинки.
